# fps_hud

HUD client-side simples que exibe o FPS no canto superior esquerdo.

Copie a pasta para `Hdd:\FiveX\Resources\fps_hud`, atualize a lista de
resources pelo menu do FiveX e inicie `fps_hud`.

Posição, dimensões, intervalo de atualização e cores ficam em `config.lua`.
Ao parar a resource, o desenho desaparece automaticamente no frame seguinte.
